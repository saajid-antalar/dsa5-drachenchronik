# DSA5 – Drachenchronik

Foundry VTT V14 / DSA5 8.1.x.

## Tagesereignis-Generator der Khôm

Das Modul verwendet die zentrale Foundry-Weltzeit und den aktiven Aventurien-Kalender für die Tages-Sperre. Pro aventurischem Kalendertag wird weltweit höchstens ein Ereignis ausgelöst. Der Generator würfelt aus gewichteten Ereigniskategorien und bestimmt, ob die ganze Gruppe oder ein einzelner Held betroffen ist.

Beim Start der Welt erstellt das Modul die Makros **☀️ Tagesereignis** und **☀️ Tagesereignis – GM Reset**. Das Ergebnis erscheint ausschließlich bei der Spielleitung als Dialog und Whisper.

Dieses Modul enthält derzeit keine Compendium-Packs.
